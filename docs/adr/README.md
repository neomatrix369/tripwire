# Architecture Decision Records

Formal ADRs for durable technology and boundary choices.

Planning-level decisions (slice waivers, priority, review skips) stay in
[plan/DECISIONS.md](../plan/DECISIONS.md). Use an ADR when the choice should
outlive a single slice and constrain packaging or runtime topology.
